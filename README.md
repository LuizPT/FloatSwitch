# FloatSwitch

Launcher flutuante leve para alternar rapidamente entre aplicações Android, mantendo os atalhos acessíveis sobre outras aplicações.

## Descarregar

[⬇️ Descarregar FloatSwitch v0.2 beta 1](https://github.com/LuizPT/FloatSwitch/releases/download/v0.2-beta1/FloatSwitch-v0.2-beta1-debug.apk)

[Consultar todas as versões](https://github.com/LuizPT/FloatSwitch/releases)

## Estado

- Versão actual: `v0.2-beta1`
- Estado: beta
- Android mínimo: Android 8.0/API 26
- Dispositivo principal de teste: Android 14, 1920×720, horizontal

## Funcionalidades

- Uma a seis aplicações configuráveis
- Ícones reais das aplicações
- Reordenação, alteração e remoção de atalhos
- Atalhos móveis com encaixe nas margens
- Posição persistente
- Bloqueio de posição
- Controlo ON/OFF
- Arranque automático
- Recuperação após reinício
- Ícone adaptativo e temático

## Privacidade

- Sem acesso à Internet
- Sem publicidade
- Sem analytics
- Sem conta
- Sem recolha ou transmissão de dados

## Instalação

1. Descarregar o APK.
2. Autorizar temporariamente a instalação de aplicações através do navegador ou gestor de ficheiros utilizado.
3. Instalar o APK.
4. Para actualizar, instalar por cima da versão anterior sem a desinstalar.

Esta é uma versão beta assinada com uma chave de desenvolvimento e destina-se a testes.
